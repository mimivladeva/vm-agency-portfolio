# VM Agency — Website Portfolio

A portfolio presentation of the **VM Agency website design and development project**.

This repository contains a clean and responsive portfolio page created to showcase the VM Agency website, bringing together the original Figma design, the live website and its source code.

## Project Overview

The goal of this project was to create a modern, minimal and professional digital presence for VM Agency, presenting its services and brand identity through a clear and engaging website.

The website was designed in Figma and developed using HTML5, CSS3 and JavaScript, with a focus on responsive design, usability and visual consistency.
